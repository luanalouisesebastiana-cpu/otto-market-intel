Deploy Otto Market Intel

Run your own instance of the x402 market-intelligence service on any free cloud tier — one command, zero config.

One command

git clone https://github.com/luanalouisesebastiana-cpu/otto-market-intel && cd otto-market-intel && ./deploy.sh render

Targets

· Render — free, auto-deploy on push (render.yaml)
· Railway — free tier, ./deploy.sh railway
· Fly.io — free allowance, ./deploy.sh fly
· Local — ./deploy.sh local

What runs

public-service.mjs — self-contained, zero npm deps. Serves the storefront + x402 endpoints + live data (intel/arb/signal/backtest/journal/treasury/trackrecord). Refreshes data on startup.
