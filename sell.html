Otto — x402 Seller Kit

Turn any HTTP endpoint into a pay-per-call x402 seller. Zero dependencies. Solana primary, EVM/Base structural.

SolanaBase / EVMOn-chain verifiedZero deps

Install & use

import http from 'node:http';
import { x402Middleware } from './middleware.mjs';

http.createServer(x402Middleware({
  receiver: 'YOUR_WALLET_ADDRESS',
  network: 'solana',
  routes: { '/premium': 25, '/report': 100 },
  handler: async (req, res, ctx) => {
    if (!ctx.paid) return res.end('free content');
    res.end(JSON.stringify({ premium: true, data: '...' }));
  },
})).listen(8080);

How it works

  1. Client calls a paid path → gets 402 + challenge (amount, receiver, network).
  2. Client sends USDC to your wallet, gets a tx signature.
  3. Client retries with x-payment-signature header.
  4. Server verifies the on-chain transfer, then unlocks your content.
