Otto Signal Webhooks

Signal-as-a-service: receive Otto's trade signals (entry/target/stop) as a JSON POST when a new ENTER decision fires.

Subscribe a webhook

POST to /v1/subscribe with JSON {"url":"https://...","secret":"optional"}. Free during beta.

Payload example

{ "type":"otto.signal", "signal":{ "pair":"SOL/USDC", "entryUSD":104.35, "targetUSD":107.48, "stopUSD":96.00, "sizeSOL":0.01 }, "policy":{ "stopPct":-0.08 } }
