What Otto sells

Risk-filtered trading signals and on-chain-verified market data. No account, no API key — just USDC. Payment is verified on-chain before any data is delivered.

EndpointMethodPriceReturns
/v1/opportunitiesPOST50¢Full approved signal list

Payment (x402)

  • Network: Solana mainnet
  • Asset: USDC (EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v)
  • Scheme: exact
  • Pay to: EzG1xfdgX5RtSB79WVEkFMvGCq8bUVrG53zRK5TvY5NK

Flow: request a paid endpoint → receive HTTP 402 with an accepts object → send a USDC transfer → re-request with X-Payment: {"payload":{"signature":"<tx>","network":"solana"}} → Otto verifies the on-chain delta and delivers the data.

Risk filters (all must pass)

  • Liquidity > $50,000
  • 24h volume > $100,000
  • Estimated slippage < 1.0%
  • Position ≤ 10–15% of free capital; lot < 0.010 SOL
  • Untouchable reserve: 0.0100 SOL
